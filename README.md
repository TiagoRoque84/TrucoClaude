# 🃏 Truco Brasileiro

Jogo de Truco Brasileiro completo com tutorial interativo e IA para jogar no celular ou computador.

## 🎮 Jogar Online

**[👉 Abra o jogo aqui: https://TiagoRoque84.github.io/TrucoClaude/](https://TiagoRoque84.github.io/TrucoClaude/)**

## Funcionalidades

- 📚 **Tutorial interativo** — Aprenda as regras passo a passo, mesmo sem nunca ter jogado
- 🤖 **Jogar contra IA** — Oponente com 3 níveis de dificuldade
- 📱 **Responsivo** — Funciona no celular e no computador
- 🇧🇷 **Truco Paulista** — Regras completas, incluindo truco, seis, nove e doze

## Como rodar localmente

Basta abrir o arquivo `index.html` no navegador — sem necessidade de servidor ou dependências.

```
git clone https://github.com/TiagoRoque84/TrucoClaude.git
cd TrucoClaude
# Abra index.html no navegador
```
